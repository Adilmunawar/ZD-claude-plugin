### Install

Claude Code:
```
/plugin marketplace add https://github.com/Adilmunawar/ZD-claude-plugin.git
/plugin install zaraat-dost@zaraatdost
```

Standalone CLI (no registry account needed):
```
npm i -g https://github.com/Adilmunawar/ZD-claude-plugin/releases/download/v7.3.3/adilmunawar-zd-tools-7.3.3.tgz
```

Offline: download the archive below, then `claude plugin marketplace add ./ZD-claude-plugin-7.3.3`.

Assets are verified in CI: the archive passes `claude plugin validate` and the tarball is installed and executed before publishing. Checksums in `SHA256SUMS.txt`.
