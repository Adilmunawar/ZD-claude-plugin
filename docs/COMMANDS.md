|---|---|---|

| Command | Purpose |
|---|---|
| `/zd-vector:gap-analysis` | Compare a digitised/mapped parcel layer against an AOI or reference layer to find missing coverage, quantify it, and produce a "missing" layer and summary. Use for coverage QA, "what's not mapped yet", or comparing two versions of a layer. |
