# zaraat-dost — the one-line install

Meta-plugin that depends on every `zd-*` module, so a single command installs the full toolkit:

```
/plugin marketplace add adilmunawar/ZD-claude-plugin
/plugin install zaraat-dost@zaraatdost
```

Adds: `/zaraat-dost:help`, `/zaraat-dost:doctor`, `/zaraat-dost:setup`, and a one-line session banner.
Modules stay individually installable (`/plugin install zd-vector@zaraatdost`) for people who only need one.
