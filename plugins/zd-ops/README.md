# zd-ops

| Component | Type | Purpose |
|---|---|---|
| `/zd-ops:incident` | command | Severity, mitigation, status updates, evidence |
| `/zd-ops:postmortem` | command | Blameless postmortem with action items |
| `/zd-ops:runbook` | command | Service runbook with verified commands |
| `observability` | skill | Logging, metrics, alert thresholds |
| `/zd-ops:oncall-handoff` | command | Weekly hand-over document |

Depends on zd-deploy for service profiles.
