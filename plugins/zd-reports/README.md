# zd-reports

| Command | Purpose |
|---|---|
| `/zd-reports:deliverable-memo` | One-page hand-over note for a layer/report |
| `/zd-reports:harvest-report` | Client harvest progress report (docx/pptx) |
| `/zd-reports:layer-metadata` | Metadata JSON + MD for any layer |

Uses Anthropic's document skills (docx/pptx/xlsx) when available.
